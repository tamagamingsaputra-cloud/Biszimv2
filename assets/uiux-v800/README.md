# BizSim UI/UX v8.0.0 asset pack

These are real local files included in the game project (not links that only exist in Canva):
- `icons/*.svg`: scalable icon assets for dashboard, market, investments, business, career, education, profile, people, calendar, wallet, creator and notifications.
- `illustrations/market-terminal.svg`: local vector artwork used by `web/v800-redesign.css` as the Asset Market header visual.

The editable Canva presentation is the design reference. Local SVG files are the in-project assets. Market illustration is decorative only; all displayed market values and chart history continue to come from the simulation engine.
