# Canva Design Reference — BizSim v8.3.0

Canva design created for visual reference: https://canva.link/56s2w6ydy33wdsv

The Canva presentation is a design artifact, not a runtime dependency. Game runtime assets must be bundled locally. This release bundles local SVG icons and avatar samples under `web/assets/uiux-v830/`; the existing SVG character editor remains active. The Canva design itself has not been exported as a runtime asset, so it is not falsely represented as included in the game bundle.
