# BizSim UI/UX refinement — v7.6.0

## Implemented
- Added `web/v760-ui.css` as an additive responsive visual layer; existing global navigation and page routes remain unchanged.
- Added `web/v760-ui.js` to apply the BizSim 7.5.0 product/build label and accessible simulated-market labels without replacing core rendering or engine endpoints.
- Updated the HTML title and loading message to BizSim 7.5.0.
- Kept Dashboard empty-state messaging tied to actual state, with no invented business or investment progress.
- Made market price movement deterministic from persisted `market.rngState`; each tick advances the saved PRNG state. This applies to the Netlify API engine and local engine copy.
- Added the visual mockup at `docs/mockups/BizSim-UIUX-Mockup-Desktop-Mobile.png`.

## Existing data reused
- Business cards use the actual business catalog served by the engine; current source has 15 business types after extras are merged.
- Job listings use the engine's job catalog and actual application status.
- Asset Market remains SIMULATED and uses engine prices/history for BTC, BBCA, and TLKM.
- Long-term Investments remains a separate page from Asset Market.

## Known data limitations retained rather than fabricated
- Market history currently stores numeric price samples (up to 30) without a timestamp per sample. Therefore, intraday/1D/7D/30D selectors cannot be truthfully mapped to time ranges yet; adding those controls requires timestamped history in the engine and a migration for existing saves.
- Simulated market volume is not present in the current market state, so it is not displayed as if it were real data.
- Investment catalog's current engine config sets `returnRange` to `[0, 0]`; the UI must not imply active category-specific valuation changes until the investment engine supports them.
- Daily income is not presented as a realized amount where the source state only provides monthly salary.

## Validation
- `npm run test:all` passed, including syntax checks, v7.4 clock tests, creator tests, engine end-to-end tests, education tests, and smoke tests.
