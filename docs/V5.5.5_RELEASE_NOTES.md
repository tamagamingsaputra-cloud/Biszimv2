# BizSim v5.5.5

## Scope
Non-breaking UI/UX and runtime integration release built on the existing v5.1 package. Existing engine/UI/backend files are preserved. New runnable web shell and server layer are additive.

## UI/UX
- Enterprise simulation dashboard inspired by the supplied reference, with the rightmost reference used as the main visual direction.
- Navy/teal/white design system, restrained shadows, dense-but-readable cards, charts, tables, status badges and clear hierarchy.
- Desktop sidebar + mobile bottom navigation.
- Touch-friendly controls, responsive grids, focus states and reduced-motion support.
- No emoji used as UI icons.
- Dedicated UI patterns for business incidents, investor offers/negotiation, transactions, finance, market, career, HR, suppliers, events and calendar.
- Loading/error/empty/success/confirmation patterns are represented in the interface.

## Runtime/backend
- Added `server/server.js` using Node's built-in HTTP server.
- Added `server/db.js` using Node 22's built-in SQLite API.
- Authentication: register/login/logout, scrypt password hashing, HttpOnly session cookie.
- Server-side persistence for player state, businesses, incidents, investors, transactions, loans, events, notifications and achievements.
- New players start with Rp0, no assets, no business, unemployed, reputation 0.
- Business loans require an existing business and financial coverage.
- Asset sell transactions validate holdings; negative/invalid quantities are rejected.
- API health endpoint reports version and SQLite status.

## Important boundary
The original v5.1 archive did not contain the original application entry point, router, database adapter or full server runtime; it contained modular engines/UI additions and generic backend routes. Therefore v5.5.5 adds a runnable integration shell rather than pretending that missing legacy runtime files were tested. The original modules remain in place.
