# BizSim 7.3.1 — Dashboard, Market, Business, Career, Creator Studio

Semua perubahan bersifat aditif (file baru + bungkus fungsi lama). Struktur navigasi global tidak diubah.

## Yang diubah / ditambah
| Area | File | Isi |
|---|---|---|
| Dashboard | `web/v730-dashboard2.js/.css` | Level karakter (dari reputasi), tanggal simulasi, utang, ringkasan investasi/bisnis, aktivitas terbaru nyata, empty state pemain baru. |
| Asset Market | `web/v730-market2.js`, `netlify/functions/api.mjs` | Badge SIMULATED, sentimen, volatilitas, avg cost, BUY & SELL, unrealized P/L, **realized P/L tersimpan di transaksi** (engine), validasi saldo/qty. |
| Business | `web/v730-business2.js` | **Perbaikan bug**: tombol "Open Business" tidak mengirim `catalogId` sehingga selalu 404. Detail bisnis, parameter awal, status terkunci + alasan, konfirmasi modal. |
| Career | `web/v730-career2.js` | Riwayat/status lamaran (sudah dicatat engine, belum tampil), detail pekerjaan + estimasi peluang (bukan kepastian). |
| Creator Studio | `netlify/functions/v731-creator.mjs`, `web/v730-creator2.js`, `web/v731-creator.css` | YouTube/TikTok/Instagram dengan capability config sendiri (Twitch = slot siap diisi). Antrean produksi berbasis state, publish/jadwal, analytics, Live Studio, gifts + fee + konversi koin, monetisasi + payout, sponsorship, skill & equipment, tier karier. Fitur kreator lama tetap ada di tab "Fitur Lama". |

`web/engine/*` adalah hasil generate dari `netlify/functions/*` (`npm run sync:local`).

## Pengujian
- `npm run check` — syntax semua file.
- `npm run test:creator` — uji engine kreator (akun, validasi format per platform, progres, biaya, publish, live, gift+fee, payout, reload) + smoke render UI 13 tab x 3 platform.
- `npm run test:e2e` — end-to-end lewat handler engine asli (daftar, lamar, katalog bisnis, market buy/sell + realized, kreator, login ulang).
- `npm run test:smoke` — smoke server lama (regresi).
**Belum diuji:** tampilan di browser/Android sungguhan (tidak ada browser di lingkungan pembuatan). Uji visual manual masih diperlukan.

## Belum ada / keterbatasan jujur
- Investments: diaudit, sudah memuat saham/emas/tanah/properti/obligasi, kupon, jatuh tempo, risiko, SIMULATED & estimasi vs realized — tidak diubah.
- Grafik Asset Market hanya punya buffer 30 tick (tidak ada rentang 1D/7D/30D sungguhan di data), jadi tidak dipalsukan.
- Career: belum ada sistem promosi otomatis, jam kerja, atau data tingkat persaingan di engine (yang ditampilkan adalah estimasi berlabel).
- Business: risiko dasar sama untuk semua bisnis (nilai tetap engine); ketersediaan lokasi belum dimodelkan.
- Creator: Twitch/Facebook baru slot arsitektur; merchandise belum ada; copyright hanya model sederhana.
