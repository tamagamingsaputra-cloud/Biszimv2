# BizSim 6.0.0

Major additive UI/UX redesign on v5.5.5.

- New control-hub layout and responsive workspace.
- Previous UI remains available inside legacy feature modules; it is not treated as the universal design.
- Inline vector illustrations for characters, food, drinks, businesses, jobs, interviews, news, land, investment and markets.
- Mobile bottom navigation and touch-sized controls.
- Investor discovery uses business metrics to derive valuation, investment, equity, risk and terms.
- Investor acceptance and counter-offers are evaluated server-side and may be rejected.
- Existing SQLite persistence and API routes are retained.
