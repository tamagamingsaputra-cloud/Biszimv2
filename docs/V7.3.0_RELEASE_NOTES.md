# BizSim v7.3.0

Update aditif dari v7.2.0 (folder induk tetap `BizSim-v7.1.0`). Tidak ada fitur atau kode lama yang dihapus. File baru: `netlify/functions/v730*.mjs`, `web/v730-*.js`, `web/v730-theme.css`. Perubahan di file lama hanya hook dan perbaikan kecil (`api.mjs`, `index.html`, `v700.mjs`, `v700-engine.mjs`, `v720-invest.js`).

## 1-2. Desain ulang UI/UX dan ikon/gambar
- Tema baru "classic elegant": ivory/navy/emas/burgundy, tipografi serif (Adobe Fonts Noto Serif) untuk judul.
- **Masthead unik per halaman** menggantikan header generik "Workspace ... simulation state server" yang sama di semua halaman — setiap section (Career, Business, Investment, Team, dst.) punya warna, ilustrasi, dan 3 statistik sendiri.
- **Set ikon baru** (garis dupleks) untuk seluruh navigasi dan tombol; ikon lama tetap jadi cadangan bila ada nama yang belum dipetakan.
- **Ilustrasi vektor baru** untuk 15 jenis bisnis, pekerjaan, fitur sidebar, dan aset investasi — tidak ada lagi gambar generik/kurang jelas seperti "beli lahan" atau kartu pekerjaan kosong.
- **Logo monogram** untuk saham (lingkaran warna sektor + kode ticker) dan koin untuk kripto — bukan logo merek asli.
- Toast dirapikan (anti-tumpuk, maksimal 3, tidak duplikat), modal jadi bottom-sheet di mobile, transisi halaman halus, tombol FAB "Simulate Day", angka beranimasi.

## 3. Task Board diperbaiki
Sistem tugas baru dan nyata (bukan tampilan statis): tugas otomatis mengikuti kondisi game sungguhan (dapat kerja, selesai pelajaran, kumpulkan dana darurat, investasi pertama, buka bisnis, tangani insiden) dan pindah kolom Belum Dikerjakan → Sedang Dikerjakan → Selesai ketika syaratnya benar-benar terpenuhi. Bisa juga menambah tugas manual sendiri.

## 4. Progress bar di Dashboard
Kartu "Progres Saya" di bawah profil menampilkan bar training/education yang sedang berjalan serta bar tugas dan dana darurat.

## 5. Portfolio Analytics dirombak
KPI kekayaan bersih (beranimasi), grafik tren, donut alokasi 11 kelas aset, tabel kepemilikan saham dengan logo dan P/L, posisi trading dengan margin, empat indikator risiko (konsentrasi, diversifikasi, leverage, likuiditas), dan riwayat transaksi saham.

## 6. Header seragam diperbaiki
Masthead sekarang unik per halaman (lihat poin 1-2), bukan satu template yang sama untuk semua fitur.

## 7. Grafik saham dan trading sekarang bergerak real-time
- Harga diperbarui tiap 3 detik lewat `/api/v730/live`, mengikuti faktor simulasi (impuls berita 1-3 hari terakhir, momentum indeks, volatilitas makro) dengan arah dan besaran unik per aset per pemain — tidak pernah mengulang pola yang sama.
- Pergerakan tetap dibatasi dalam rentang wajar dari harga penutupan harian, lalu mengikuti harga penutupan baru saat hari simulasi berganti.
- Order beli/jual saham dan buka/tutup posisi trading sekarang mengeksekusi di harga live tersebut, bukan harga statis.
- Trading Terminal mendapat timeframe tambahan (15m, 30m, 4H), statistik pasar (High/Low/Volume/Spread/Sentimen/Volatilitas), dan tombol yang berubah sesuai posisi (Close LONG/Tambah LONG, dst.) seperti diminta.

## 8. Perbaikan sistem lain
- Riwayat transaksi saham (`v700.tx`) dan realized P/L (`v700.realized`) dicatat setiap beli/jual, ditampilkan di Portfolio Analytics.
- Kartu pekerjaan di Career memakai ID yang benar (sebelumnya rawan salah kutip) dan gambar sesuai jenis pekerjaan.
- Fuzzing otomatis pada 114 rute API tidak menemukan error server.

## Catatan
- Berjalan di mode lokal (`web/engine`, tanpa server) maupun backend Netlify. Jalankan `npm run sync:local` setelah mengubah `netlify/functions`.
- Pergerakan harga tetap simulasi, bukan data pasar nyata.
- Canva tidak tersedia pada sesi pembuatan update ini; desain memakai palet dan tipografi Adobe Fonts yang sudah terpasang di kode.
