# BizSim 6.1.0 — Bug Update

This release is intentionally incremental. The original BizSim UI structure, navigation, visual language, simulation screens and existing feature modules are retained.

## Fixed
- Netlify production no longer depends on a manually entered frontend backend URL.
- Removed `api-config.js` and all frontend API-key/backend-URL instructions.
- Auth requests now use credentials and robust JSON handling.
- Explicit submit/button types prevent accidental form behavior.
- Same-origin Netlify Function provides the `/api/*` backend.
- Original frontend API contracts are preserved, including business incidents, investor offers, loan fields and market BUY/SELL handling.
- Numeric IDs are retained for inline UI handlers.
- Mobile menu uses the existing SVG icon system and opens as a drawer; no phone emoji or emoji navigation was added.

## Preserved
- Original BizSim page structure and visual design system.
- Existing career, business, operations/risk, finance, market, portfolio, people, suppliers, events, calendar and profile pages.
- Existing server/SQLite implementation for local/self-hosted use.

## Production storage
Netlify production uses Netlify Blobs through `netlify/functions/api.mjs`. Local/self-hosted development continues to use the existing Node + SQLite server.
